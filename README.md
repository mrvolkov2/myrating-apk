## 📥 Как установить APK на устройство

1. Скачайте файл **`myrating.apk`** из этого репозитория (или по кнопке «Скачать APK» выше).
2. Откройте скачанный файл на вашем Android-устройстве.
3. При необходимости разрешите установку из **«Неизвестных источников»** в настройках вашего браузера или файлового менеджера.
4. Нажмите **«Установить»** и запустите приложение.
